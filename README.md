# Интернет-магазин

Учебный проект — интернет-магазин, сделан в рамках летней практики.

Бэкенда своего нет, вместо него используется MSW (Mock Service Worker - библиотека для имитации (мока) сетевых запросов, которая перехватывает реальные HTTP-запросы на уровне браузера или тестов, позволяя разрабатывать и тестировать React-компоненты без реального сервера) — он перехватывает запросы к `/api/...` прямо в браузере и отдаёт данные из моковой "базы", так что реального сервера поднимать не нужно.

## Стек

- TypeScript
- Zustand — для стейта (сессия пользователя, корзина)
- MSW — эмуляция бэкенда
- Обычные CSS-модули

## Запуск

```
npm install
npm run dev
```

Дальше открыть `http://localhost:5173`.

Собрать проект: `npm run build`
Проверить линтером: `npm run lint`

## Роли

Есть три роли: гость (не залогинен), обычный пользователь и админ.

Чтобы зайти под админом:
```
admin@shop.dev
admin123
```

Под админом появляется страница `/admin`, где можно добавлять и удалять товары. Обычного пользователя можно завести через регистрацию — но так роль всегда будет `user`, админом через форму стать нельзя (специально так сделано).

## Что есть в проекте

Главная с фильтрами и поиском, страница товара, корзина (только для залогиненных), профиль, вход/регистрация и админка. Корзина и добавленные/удалённые товары сохраняются в localStorage, так что после перезагрузки страницы всё останется на месте.
